プライバシーポリシー (Windows版)

ShifNoa(シフノア) Windows版 / 制定日: 2026年10月17日

ShifNoa Windows版(以下「本ソフト」)の提供者であるシフトノア(以下「提供者」)は、情報の取り扱いについて、以下のとおり定めます。iPhone / iPad 版には、別のプライバシーポリシーがあります。

1. 基本の考え方

職員の名前や勤務表などのデータは、提供者のサーバーにも、第三者にも送られません。お使いのパソコンの中だけに保存されます。本ソフトには、会員登録・ログイン機能、広告、アクセス解析はありません。

2. パソコンの中に保存されるデータ

ユーザーが入力した次のデータは、お使いのパソコンの中にのみ保存されます。提供者は閲覧できません。

  • 病棟名・チーム名・職員の名前、レベル、所属チーム、勤務に関する設定
  • 勤務表、希望の登録内容、変更履歴
  • 必要人数などの各種設定値

データは、本ソフトをアンインストールしても残ります。完全に消したいときは、サポートページの案内に従って、データのフォルダを削除してください。パソコンの故障などに備え、バックアップ機能(任意でパスワードによる暗号化ができます)や、CSV / Excel / PDF の出力を使って、保管してください。

3. 本ソフトが通信する相手と、送られる情報

本ソフトが通信するのは、次の2つだけです。それ以外への通信は、本ソフトの内部で遮断しています。

  • ライセンスの確認(提供者のサーバー。Cloudflare 上で運用): 1日に1回程度、ライセンスキー(または施設コード)を送ります。サーバーは、キーそのものではなくその変換値(ハッシュ)、利用状況(有効・無効)、有効期限、Stripe の契約を識別する番号を保存します。施設コードに付ける施設のルール(必要人数や勤務の条件などの設定)も保存しますが、職員名や勤務表などは含みません。
  • 新しい版の確認(GitHub): 起動時と6時間ごとに、新しい版があるかを確認します。職員名や勤務表などは送りません。

どちらの通信でも、通信の仕組み上、お使いの回線の IP アドレスなどが、相手のサービスに届きます。提供者は、これを利用者の特定やアクセス解析には使いません。Cloudflare と GitHub は、それぞれのサービスの運営のために、通信の記録を保存することがあります。

4. お申し込みとお支払い(Stripe)

お申し込みとお支払いは、決済サービス Stripe の画面で行います。Stripe には、メールアドレス・お名前・ご住所、(お支払い方法を登録する場合は)カード情報を入力いただきます。カード情報は Stripe が取り扱い、提供者は受け取りません。メールアドレス・お名前・ご住所は、契約の管理・請求書の発行・お問い合わせへの対応のために、Stripe を通じて提供者が確認できる場合があります。これらは、その目的以外には使いません。Stripe での取り扱いは、Stripe のプライバシーポリシーに従います。

5. お問い合わせ

お問い合わせの際にいただいた情報は、返信と対応のためだけに使います。お問い合わせには、職員の氏名や勤務表の内容を書かないでください。

6. 勤務表の出力

「CSV / Excel / PDF の出力」やバックアップを行うと、ファイルがユーザーの選んだ場所に保存されます。保存したファイルを、メールやクラウドストレージなどに送るかどうかは、ユーザーご自身で決めます。送信先での取り扱いは、各サービスの規約に従います。

7. 個人情報の取り扱いについてのお願い

本ソフトには職員の氏名が入力されます。職場の規程に沿って、氏名を略称や記号にする、出力したファイルを適切に管理するなど、ご注意のうえでご利用ください。

8. 第三者への提供

提供者は、法令に基づく場合を除き、ユーザーの情報を第三者に提供しません。上の3・4で書いた各サービス(Cloudflare・GitHub・Stripe)は、本ソフトの提供に必要な範囲で利用しています。

9. ポリシーの変更

本ポリシーは、必要に応じて改定することがあります。重要な変更は、このページに掲載してお知らせします。
